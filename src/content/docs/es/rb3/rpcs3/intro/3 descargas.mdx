Antes de iniciar con la instalación, **asegúrate que tus drivers y sistema operativo estén actualizados.**

<Aside type="danger">**¡NO instales el emulador a un USB externo o una carpeta sincronizada (Dropbox, OneDrive, etc.)!  
Puedes mover los archivos del juego después si necesitas, ¡pero el emulador siempre debe de estar instalado en un disco interno!**</Aside>

## Prerrequisitos
**Empezamos descargando 7-Zip**, porque va ayudar abrir mayoría de los archivos que bajamos en esta guía. **Si ya tienes 7-Zip** o una alternativa instalada, **puedes seguir adelante**.

<a href="https://7zip-es.updatestar.com/" target="_blank" rel="noopener noreferrer"><b>[Haz clic aquí para ir a la página de descarga de 7-Zip]</b></a>.  
> <a href="https://7zip-es.updatestar.com" target="_blank" rel="noopener noreferrer"><Image src={windl7zip} alt="La pagina para descargar 7-Zip, con el cursor sobre el instalador .exe de 64 bits" /></a>

**Ahora**, **vamos a instalar Microsoft Visual C++ 2019 Redistributable**, porque es necesario para RPCS3. La mayoría de computadoras ya lo tienen, pero no está mal estar seguro.  
<a href="https://aka.ms/vs/17/release/vc_redist.x64.exe" target="_blank" rel="noopener noreferrer"><b>[Haz clic aquí para descargar Microsoft Visual C++ 2019 Redistributable]</b></a>

**Cuando se descargue**, **ábrelo e <span title="Install">`instálalo`</span>**.  
> <a href="https://aka.ms/vs/17/release/vc_redist.x64.exe" target="_blank" rel="noopener noreferrer"><Image src={winmvcpp} alt="El instalador de Microsoft Visual C++ 2019 Redistributable, con las condiciones y opción para instalar." /></a>

## RPCS3
**Después, vamos a descargar RPCS3**.  
<a href="https://rpcs3.net/download" target="_blank" rel="noopener noreferrer"><b>[Haz clic aquí para ir al sitio de descarga de RPCS3]</b></a>.

Desliza hacia abajo y descarga la versión de Windows.

> <a href="https://rpcs3.net/download" target="_blank" rel="noopener noreferrer"><Image src={winrpcs3dl} alt="El sitio de descarga para RPCS3, con el cursor en la versión de Windows." /></a>

**Cuando termine de descargar, extrae el archivo `.7z`.**  
> <Image src={winextractrpcs3} alt="El menú contextual de Windows con el cursor en 'Extraer ficheros...'" />

Es recomendado que extraigas todo a `C:\Juegos\RPCS3` o en un disco interno adicional para evitar problemas de permisos. También desactiva la opción para crear un subdirectorio, como en la imagen.  

> <Image src={winextractdir} alt="La ventana de extracción de 7-zip. Muestra 'Extract to' (Extrae archivos...) como C:\Juegos\RPCS3 y el cuadro debajo de ella desmarcada." />

## RPCS3
**Empezamos descargando RPCS3**.

<a href="https://rpcs3.net/download" target="_blank" rel="noopener noreferrer"><b>[Haz clic aquí para ir al sitio de descarga de RPCS3]</b></a>.

Desliza hacia abajo y descarga la versión de Linux.

> <a href="https://rpcs3.net/download" target="_blank" rel="noopener noreferrer"><Image src={nixrpcs3dl} alt="El sitio de descarga para RPCS3, con el cursor en la versión de Linux." /></a>

**Cuando termine de descargar**, se recomienda que **coloques el archivo `AppImage` en un lugar conveniente**.  
Ahora, abre una terminal en la carpeta donde esta el archivo `AppImage`.  
> <Image src={nixrpcs3terminal} alt="Abriendo una terminal en Plasma." />

Ejecuta este comando:
```bash
chmod a+x ./rpcs3-*_linux64.AppImage && ./rpcs3-*_linux64.AppImage
```
> <Image src={nixrpcs3chmod} alt="Una terminal con el comando chmod listo para ejecutar." />

## Firmware
Después de eso, [[descarga el software del sistema de PlayStation 3 del sitio de Sony]](https://www.playstation.com/en-us/support/hardware/ps3/system-software/). **Mira un poco abajo en la página** hasta que llegues a "**Actualizar por computadora**", haz click en eso para expandirlo y luego haz click en "**Descargar la actualización de la PS3**".

_**Si estás utilizando un navegador Chromium como Chrome o Edge, ASEGÚRATE DE HACER click DERECHO Y "Guardar enlace como..." o tu descarga PUEDE FALLAR.**_

> <a href="https://www.playstation.com/support/hardware/ps3/system-software" target="_blank" rel="noopener noreferrer"><Image src={fwpage} alt="La página de 'Cómo actualizar el software del sistema de la consola PS3' de Sony con la subcategoría 'Actualización por computadora' expandida" /></a>
